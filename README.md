# 🕹️ Loja de Jogos

Este projeto é uma aplicação Angular **standalone** desenvolvida como atividade de estudo para manipulação de componentes, roteamento e consumo de API. O sistema permite a **visualização, cadastro, edição e exclusão** de produtos (jogos) em um painel gerenciado.

## ✨ Funcionalidades
- 📄 **Painel Principal**: Lista de produtos disponíveis.
- 📝 **Cadastro de Produto**: Adicionar novos produtos com nome, descrição, foto e preço.
- 🔄 **Edição de Produto**: Atualizar informações de um produto existente.
- 🗑️ **Exclusão de Produto**: Remover um produto do catálogo.
- 🔗 **Navegação via Angular Router**: Permite troca dinâmica entre páginas sem recarregar a aplicação.

## 🛠️ Tecnologias
- **Angular 19 (standalone mode)**
- **TypeScript**
- **JSON Server** (fake API)
- **Bootstrap 5** (interface responsiva)
